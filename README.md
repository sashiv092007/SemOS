# SemOS

A semester workspace for students: exam cheat sheets, assignment scheduling and a live deadline countdown.

## What works today

- **Landing page** (`/`) with a preview of the Mastersheet workspace.
- **Roadmap** (`/roadmap`): enter your assignments, the hours each needs and the days you have. SemOS orders them largest first, splits the time between them and counts down to the deadline (`7 days:00h:00min`). The plan is saved in your browser; no account needed.
- **Cheat sheet template** (`/template`): the printable sheet layout with sample content.

## Planned

Textbook topic sorter, one-click cheat sheets from uploaded chapters, a spoiler-free LeetCode concept decoder, a syllabus-to-CGPA strategist, and sign-in to sync plans across devices.

## Run it locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

Built with Next.js, React, Tailwind CSS and TypeScript.
